# BRO · 星空主页

## 响应式布局规范

全站外框、导航与页脚共用 `assets/css/style.css` 中的布局变量：`--site-max:1440px`，左右安全边距由 `--site-gutter` 在16～48px间连续变化。列表、首页下方内容和图谱使用外框；文章、资源详情和关于页的标题及文字按960px阅读宽度居中；文章媒体最多1120px。宽屏目录放在对称侧列，不参与正文宽度分配；平板与手机使用折叠目录。

页面顶部、标题间距及底部留白分别由 `--page-top`、`--heading-gap`、`--page-bottom` 管理。图谱复用同一外框，组件内的热力滚动和全屏仍独立处理；不再用负边距扩张页面。图谱标题通过共享渲染函数生成。资源卡片始终先进入资源详情，再由详情中的操作链接打开工具。

运行 `python scripts/build.py` 生成页面。部署流程使用现有 Playwright 浏览器工具运行 `node scripts/layout.test.cjs`，覆盖1920、1440、1366、1024、768、430、390、375、320px、两种主题、八类页面、目录和图片放大、资源中间页和搜索导航；图谱手势及完整分析链路由现有两组图谱检查继续覆盖。可用 `QA_URL` 复查线上版本，`ATLAS_QA_OUTPUT` 指定截图和尺寸记录的输出目录。

## 覆盖与预览

1. 将压缩包中的所有文件和文件夹复制到原项目根目录，即原来 `index.html` 所在的位置，选择替换同名文件。不要额外套一层目录。
2. 本包不含 `.git`，不会替换你的 Git 仓库记录；其他未同名文件会保留。
3. 双击 `index.html` 可以本地预览，不需要安装前端依赖。
4. 如果你在上传压缩包之后又修改过文章或资源配置，保留你的最新 `posts/` 和 `resources/resources.json`，覆盖页面文件后运行 `python scripts/build.py`，重新生成文章数据。
5. 部署到 GitHub Pages 时，沿用仓库原有的提交、推送流程；包内 `.github/workflows/deploy.yml` 已更新为同时发布所有栏目和详情页面。GitHub 仓库的 Pages 来源应为 GitHub Actions。

## 页面与交互

- `index.html`：星空首页、最近文章，存在资源时显示精选资源。
- `articles.html` / `resources.html` / `about.html`：独立栏目页。
- `article.html?id=...` / `resource.html?id=...`：完整详情页。
- `search.html?q=...`：搜索文章标题、分类、正文及资源标题、说明。
- 旧的 `#articles`、`#articles/文章ID`、`#a:文章ID` 等链接仍可跳转到新页面。
- 内容在普通页面中打开。文章图片支持弹层放大、原始尺寸、Esc 关闭。

## 昼夜模式

首次访问默认夜间模式，不再跟随设备。点击右上角地球即可自转并切换主题。昼夜使用同一张星空背景，通过透明度和底色渐变过渡，星点不会重新排列。日间银河仅保留极淡痕迹。

手动选择会在页面跳转、刷新和重新打开网站时保留，并在同源标签页之间同步。优先保存到本地存储，受限时使用会话存储与主题 Cookie 回退。浏览器前进后退恢复缓存页面时会同步最新选择。没有手动选择时默认夜间模式。系统开启“减少动态效果”时跳过动画。

## 新增文章

每篇文章放在 `posts/`，格式保持原样：

```markdown
---
id: example-post
title: 文章标题
date: 11.06
year: 2026
tag: 技术笔记
---

正文，支持 **加粗**、`行内代码`、列表、引用与代码块。

![图片说明](./assets/images/example.svg)
```

图片放在 `assets/images/`。本地新增或修改文章后运行：

```bash
python scripts/build.py
```

GitHub Actions 部署前也会自动执行构建。无需手改 `assets/js/data.js`。

## 新增资源

编辑 `resources/resources.json`。当前保留你上传版本的空列表，不添加演示资源。每项可使用：

```json
{
  "id": "example-resource",
  "title": "资源名称",
  "mark": "资料",
  "desc": "资源说明",
  "type": "free",
  "url": "./resources/example.pdf"
}
```

资源链接支持本地相对路径或 HTTP/HTTPS 地址。`type` 为 `free` 时显示“获取资源”，其他值显示“前往购买”。修改后同样运行构建。

## 文件结构

- `assets/css/style.css`：电脑与手机布局、昼夜配色、阅读页面。
- `assets/js/theme-init.js`：首屏主题初始化。
- `assets/js/theme.js`：手动昼夜切换。
- `assets/js/globe.js`：保留原项目地球的三维投影、自转和明暗绘制。
- `assets/js/app.js`：页面内容、搜索、移动导航、图片放大。
- `assets/images/starfield.webp`：本地星空背景，无需外链。
- `scripts/build.py`：原 Markdown 数据构建流程。

已在浏览器检查昼夜切换、独立文章页、搜索、图片放大，以及 390px / 320px 窄屏首页和菜单。

## 首页与手机布局更新

首页按可视高度为最近文章预留空间。手机端采用左对齐双行标题，统一导航、标题与正文边距，日期和分类合并成一行；保留原有星空与昼夜连续切换。

## 稳定的页面切换

构建需安装 Python 3 和 Node.js 22 或更新版本，无需 npm 依赖。仍运行 `python scripts/build.py`，会同时更新内容数据、栏目 HTML 和每篇文章/资源的静态详情 HTML。页面正文在首屏已存在，不等待 JavaScript 填充；搜索和旧的查询参数链接继续由浏览器处理。

首页与栏目列表使用相同最大宽度，文章保留较窄的阅读区。页面始终预留滚动条位置，短页面的页脚固定在内容下方的视口底部；本地 SVG 插图在构建时写入宽高，避免图片加载后挤动正文。

## 页面空间与导航

首页保留星空主视觉的高度，桌面主标题随屏幕适度放大，保持居中的开放构图。导航、首页正文、子页面与页脚共用最大1440px的内容边界，左右边距使用同一个16～48px连续变量。文章、资源、关于、详情和搜索都使用同一组面包屑、标题、说明与内容间距，阅读页使用居中的组合布局，标题与正文共用 960px 文字栏，图表使用更宽的居中主栏。

手机导航为竖向列表，搜索使用同一套面板配色、圆角与边框，支持点击外部关闭及 Esc 返回按钮。菜单与搜索打开时不会挤动页面。

## 内容区域的比例

宽屏列表将日期、标题、分类与入口排为信息列，平板将分类收至标题下，手机继续使用两行条目。阅读页的标题、元信息和正文共用 960px 居中文字栏，插图在最大 1120px 的阅读主栏内居中，宽屏目录使用右侧对称留白，正文和插图各自居中；关于页使用适合短介绍的正文层级，空状态在明确的内容区域内呈现。没有说明文字时不再生成空的说明占位。

工作流的 checkout、setup-node、setup-python 使用 v6，Pages 上传和发布使用 v5，以使用原生 Node.js 24 的组件及上传依赖。构建脚本仍使用 Node.js 22 和 Python 3.12。

## 居中阅读与目录

阅读页的正文和媒体分别居中，目录不参与正文中心计算。文字栏最大 960px，标题、日期与正文共用左边界；图表最大 1120px，并在阅读主栏内居中。至少有三个二级标题的文章自动生成目录：宽屏使用右侧目录，较窄屏幕使用正文上方的折叠目录。无目录的阅读页和关于页使用单栏居中。目录支持锚点分享和当前章节提示，图片放大保留原有操作。
