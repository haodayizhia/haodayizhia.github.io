# 股市图谱交互验收

布局调整必须保留信息与完整研究路径。验收按用户操作链路进行，不能只检查某个按钮或绘图函数存在。

| 场景 | 必须保留的行为 | 验证 |
| --- | --- | --- |
| 首次打开 | 近三月、市场全部行业；从市场进入行业后默认全部成分 | browser / journey |
| 完整数据 | 市场四视图，行业走势及股票热力；全部股票与完整区间；缺失值留空 | engine / journey |
| 行业分析 | 行业与股票池两条基准；相对本行业/股票池切换；最新指标排序，历史悬停不重排 | engine / journey |
| 图内进入详情 | 市场曲线、市场热力和轮动可进入行业；行业曲线及股票热力可进入日线；鼠标和触摸均能完成 | journey |
| 默认与人工选择 | 行业首次全部；用户手动选择按行业保留；切换指标/视图/返回不得静默减少股票 | journey |
| 返回与链接 | 原指标、观察日、选择、横纵范围、热力滚动与全屏可恢复；公开数据直接链接/刷新可用 | journey |
| 数据源切换 | 本地预览、认证发布、恢复公开、坏文件保留原数据；令牌不得进入URL、history状态或界面缓存 | publish / CSV / 手动集成 |
| 图表交互 | 图外读数、全部值可展开；关注不锁住日期参考线；统一双轴缩放、平移、全屏、复原；鼠标移出/图外点按清掉高亮与参考线，详情入口仍可点击 | browser |
| 操作稳定 | 普通图表操作不得重新加载文档或反复调用History API；前进、后退及刷新恢复保留 | browser / journey |
| 移动与主题 | 320/390px与桌面1440px可操作；无横向页面溢出；1920/2560px图表展开；坐标文字不裁切且单位融入标题；昼夜一致；弹窗外可关闭 | browser / journey / theme |

`journey.test.cjs` 优先使用真实公开数据中的最大行业。若用户公开数据太短或成分太少，测试仅在浏览器本地导入样例，确保小数据也可正常部署；不会改写公开行情。`ATLAS_QA_FIXTURE=1` 可显式验证样例路径。
