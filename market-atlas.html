导入本地行情 · 仅自己可见

文件只在此浏览器中解析，不会上传到服务器；关闭页面后需重新导入。验证成功后才切换，失败时保留当前数据。

逐股CSV每股一个文件；合并CSV可包含全部股票，支持股票池或全市场数据。

支持的数据格式

支持全部股票合并在一个CSV，或每股一个CSV的目录。逐股文件名为六位代码.SH／.SZ／.BJ.csv；合并表按“代码＋交易日期”识别记录。必需字段：代码、名称、交易日期、所属行业、现价、涨幅%、成交额(亿元)、换手率、MA20。日期为YYYYMMDD，支持UTF-8与GB18030；其余字段可保留。新数据的价格复权方式须保持一致。

上传并发布本地行情 · 站点维护者

选择CSV后点击“上传并发布”，校验通过即更新网站公开数据。此操作需要 GitHub 仓库写权限。

令牌仅用于本次向 GitHub 发布，不保存到浏览器或网站。创建令牌 ↗，仓库选择 haodayizhia.github.io，Contents 设为 Read and write。
